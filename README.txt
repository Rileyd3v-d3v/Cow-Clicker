MOO CLICKER: PASTURE PARTY
==========================

Included:
- index.html: the game
- manifest.json: installable web app settings
- sw.js: offline cache
- cow-icon.svg: app icon

IMPORTANT: iPhone Web Clip / Home Screen installation
This bundle needs to be hosted on an HTTPS website for the full installable app experience. A ZIP or local HTML file cannot be installed as a true iPhone web app by itself.

Simple hosting route (GitHub Pages):
1. Sign in or create a GitHub account.
2. Create a new public repository, for example "moo-clicker".
3. Upload all four files (index.html, manifest.json, sw.js, cow-icon.svg) to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. Wait for GitHub Pages to provide an HTTPS URL.
7. Open that URL in Safari on your iPhone.
8. Tap Share > Add to Home Screen. If offered, choose Open as Web App, then tap Add.

The game saves progress in the browser on that device. Avoid clearing Safari website data if you want to keep your farm save.
